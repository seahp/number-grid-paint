# 双语与本地化（i18n）

界面和**纸面**一起切。右上角 `中文 | EN` 一段，或者 `?lang=en`。
英文不是逐字翻译，是按英语课堂的说法重写（"Stamp Hunt" / "Cell Battle" / "Show work"）。

## 1. 三层结构

```
S.lang  ('zh' | 'en')
   ├─ L10N_RAW  key → [中文, English]        （一张扁平表，约 140 个 key）
   │     └─ L10N.zh / L10N.en               （启动时摊平成两个字典）
   ├─ T(key) / F(key, map) / PL(n) / KN(kind)   取文案
   └─ KLANG + KM(中文, English)              内核（KERNEL 区）文案，独立开关
```

* `T(k)` — 取字符串，当前语言没有就退回中文，再没有就返回 key 本身（不会白屏）。
* `F(k, map)` — 替换 `{name}` 占位符；map 里没有的占位符**原样留着**，
  所以漏传参数会在页面上看见 `{n}`，`scripts/i18n_probe.py` 专门抓这个。
* `PL(n)` — 英文单复数：`n===1` 给 `''`，否则给 `'s'`；中文永远给 `''`。
  模板里写 `pair{z}`，调用传 `z:PL(n)`。英文 0 按复数（"0 pairs"）。
* `KN(kind)` — 和/差/积 → Sum/Diff/Prod。
* `lab(kind,t)` — 集章表标签：中文 `和=7`，英文 `Sum 7`（英文不写等号）。

## 2. 内核为什么单独一套（`KLANG` / `KM`）

`/* ===== KERNEL START/END ===== */` 之间那段会被 `scripts/verify.mjs` 用 `node:vm` 直接加载，
它的 76 项断言**按中文子串匹配**错误文案。所以内核默认 `KLANG='zh'`，
只有 `switchLang()` 会翻它；`KM('中文…','English…')` 两条都写，取哪条看 `KLANG`。
**不要把 `KLANG` 默认值改成 en**，整套数学红线会一起变红。

## 3. DOM 怎么换文案

给元素打标记，`applyLang()` 统一刷：

| 属性 | 作用 | 用在 |
| --- | --- | --- |
| `data-t` | 换文本 | 标题、按钮文字、复选框标签 |
| `data-h` | 换 innerHTML（带 `<em>`、`&amp;` 的） | 副标题、图例、提示块 |
| `data-tt` | 换 `title` 悬浮提示 | 所有 tooltip |

带 `<input>` 的 `<label>` 必须走 `setNodeText()`——它**只替换最后一个文本节点**，
直接 `textContent=` 会把复选框冲掉。

## 4. 启动顺序有讲究

```js
langInit();  params();  setKLang(S.lang);  applyLang();  sync();  render();
```

`applyLang()` 一定在 `sync()` **之前**：`sync()` 会把 ➕➖ 的手动读数
（`cellAuto` 的 textContent / title）写回去，顺序反了刚刷好的英文读数会被中文覆盖。

语言优先级：`?lang=` ＞ `localStorage('gridpaint.lang')` ＞ `navigator.language` 以 `zh` 开头。
`file://` 下 localStorage 可能写不进，读也一样包 `try`，拿不到就退回浏览器语言。

## 5. 切语言会改版面，这是设计不是 bug

拉丁词**不能像汉字那样逐字断行**，所以同一句话英文更宽，版面必须重解：

* `html[lang="en"]` 换系统无衬线字体、标题取消 `letter-spacing`；
* 集章表标签列英文更宽（`Wq` / `miniLayout` 里的 `W`：中文 15–20mm，英文 17–22mm），
  多占的宽度由 `scoreCols` 从算式格里扣 → 英文下会少并几格或多分一栏；
* 三/四栏时算式列只剩十几毫米，`"Equations I found"` 一个词就顶出去，
  所以窄列改用 `tcMineS` = **"Show work"**（教室里就在说这件事），表头同理 `tcEqS` = "Work"；
* 答案页英文副标题压到一行（`anSub`），否则会和右侧 meta 挤在同一视觉行上；
* 英文答案页不印中文口诀，改用 `eqOf()` 的原始算式。

格子大小由解算器按新文字高度重解，**不需要**为英文单独设档。

## 6. 加一条文案的流程

1. 在 `L10N_RAW` 加 `key:['中文','English']`（两条都要写，顺序固定）。
2. 界面元素打 `data-t` / `data-h` / `data-tt`；纸面在拼 HTML 处用 `T()` / `F()`。
3. 带数字的英文想清楚单复数，用 `{z}` + `PL(n)`。
4. 内核里的文案用 `KM()`，不要用 `T()`（KERNEL 区不能依赖外面的 `S`）。
5. 跑 `python3 scripts/i18n_probe.py`（占位符 / 单复数 / 漏翻 / 撑爆列）
   和 `python3 scripts/size_probe.py --lang en`。

## 7. 故意留中文的地方

* 所有代码注释——作者是中文使用者，注释讲"为什么"，翻成英文会丢信息。
* `?diag=1` 诊断探针里的串（'页面溢出'、'裁切:'、'压住页脚'…）——只在无头量测里被
  正则读，不进用户界面，也没有脚本断言它们。
